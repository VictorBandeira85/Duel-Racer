# Sprites gerados a partir de fotos

Estes sprites (e os de `src/assets/cockpit/`) foram gerados por `tools/ref/photo2sprite.py` e `tools/ref/cockpit_959.py` a partir de fotos de
terceiros encontradas na internet. Servem só para o desenvolvimento privado do projeto
e **precisam ser substituídos** (por arte própria, fotos próprias ou fotos com licença
livre) antes de qualquer publicação do jogo.
